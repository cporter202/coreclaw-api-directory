## Phase 1: Deploy (Day 1)

> ✅ **Done** — site is live at **https://coreclaw.netlify.app/** (deployed via drag & drop of `docs/`).

### Option A — GitHub Pages (free, alternative)
1. Authenticate as `cporter202` on GitHub
2. Push to repo: `git push origin main --force`
3. Go to repo **Settings → Pages**
4. Source: **Deploy from branch** → `main`, folder: `/docs`
5. Site goes live at `https://cporter202.github.io/coreclaw-api-directory/`

### Option B — Netlify (free, no GitHub needed)
1. Go to [app.netlify.com](https://app.netlify.com)
2. Drag & drop the `docs/` folder
3. Site goes live instantly with a `.netlify.app` URL
4. Optional: connect custom domain later

### Redeploy after changes
1. Run `npm run build:pages` to regenerate all 118 worker pages + sitemap
2. Drag & drop the `docs/` folder into Netlify again (or push to git if connected)

### Verify
- Open the live URL in a browser
- Search for a worker, click a category, open a modal
- Click "Try on CoreClaw" → verify `?fpr=chris69` is in the URL

### Already Done
- `docs/llms.txt` → AI chatbots cite your directory (now lists all 118 worker pages)
- `docs/robots.txt` → Google crawls everything (points to Netlify sitemap)
- `docs/sitemap.xml` → Google indexes all 130 URLs (home + 11 category pages + 118 worker pages)
- SEO meta tags in `index.html` (title, description, og tags, canonical → Netlify)
- ✅ **Individual worker pages** — `docs/workers/{slug}.html` for all 118 workers
  - Each page has full description, token summary, JSON-LD schema, CTA, related APIs
- ✅ **Category landing pages** — `docs/categories/{slug}.html` for all 11 categories
  - Each page lists its workers, has JSON-LD, prev/next category navigation
- All pages generated by `npm run build:pages` — run it after every `data.json` change
