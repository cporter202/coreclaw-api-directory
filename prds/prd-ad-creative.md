# PRD: Ad Creative Strategy — CoreClaw API Directory

## Executive Summary

This PRD defines the paid media creative strategy for the CoreClaw API Directory, covering Google Ads, Meta (Facebook/Instagram), LinkedIn, and programmatic display. The strategy focuses on developer audience acquisition through platform-specific creative approaches, performance optimization, and budget allocation across awareness, consideration, and conversion funnel stages.

## Problem Statement

Organic growth through AEO and citations is essential but slow. Paid acquisition accelerates visibility among developers actively searching for API directories, automation tools, and developer productivity solutions. The challenge is reaching technical audiences with creative that resonates without feeling like traditional marketing.

## Creative Testing Framework

### A/B Testing Priorities
1. **Headlines**: Test value props (speed vs. breadth vs. AI)
2. **Images**: Product screenshots vs. illustrations vs. abstract
3. **CTAs**: "Try Free" vs. "Explore" vs. "Get Started"
4. **Landing pages**: Single page vs. category-specific

### Testing Calendar
- Week 1-2: Headline testing
- Week 3-4: Image testing
- Week 5-6: CTA testing
- Week 7-8: Landing page testing

### Success Criteria
- Minimum 1000 impressions per variant
- Statistical significance at 95% confidence
- Winner implemented for 2+ weeks before next test

## Conversion Tracking

### Events to Track
```
Primary conversions:
- signup_complete (registration form)
- api_first_call (first API request)
- worker_view (worker detail page)

Secondary conversions:
- search_query (search performed)
- comparison_view (comparison page)
- recommendation_request (AI recommendation)
- documentation_view (docs page)
```

### Attribution Model
- Google Ads: Data-driven attribution
- Meta: 7-day click, 1-day view
- LinkedIn: 30-day click, 1-day view
- Programmatic: Last click

## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| High CPC for developer keywords | Medium | Long-tail keywords, negative keywords |
| Low CTR on technical audience | Medium | Technical creative, developer-focused messaging |
| Conversion tracking gaps | High | Server-side tracking, backup attribution |
| Ad fatigue | Medium | Creative rotation, frequency capping |
