# Product Hunt Launch

## Tagline
118 web scraping APIs, free and searchable — with health scores and AI-agent discovery (llms.txt)

## Description
A free directory of 118 web scraping and data extraction APIs across 11 categories. Instant search, per-API health scores, 118 detail pages, and category browsing. Costs $0/month to run — static site generated from one JSON file, with llms.txt so AI agents can find it too.

## Maker Comment
Hey Product Hunt! 👋

I built this directory because I was tired of Googling "best Instagram scraper" and getting outdated blog posts.

What makes it different:
- **118 tools** across 11 categories (Amazon, Instagram, LinkedIn, TikTok, Google Maps, job boards, finance, and more)
- **Instant search** — type "scrape amazon prices" and get relevant tools
- **Health scores** — see which APIs are actually working
- **118 detail pages** — each API has its own page with a summary and direct link
- **12 in-depth guides** — "best scraping APIs 2026", "scraping without code", platform-specific how-tos with FAQ schema
- **llms.txt** — ChatGPT, Claude, and Perplexity can discover and recommend the directory

Tech: plain static HTML/JS + a Node generator script, hosted on Netlify free tier. The whole thing is open source.

Try it: https://coreclaw.netlify.app/

Would love your feedback! What tools am I missing?
